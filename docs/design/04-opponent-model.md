# 对手预测（隐藏信息推断）

> 属于 [ygorl 设计文档](README.md)。状态：已评审通过（2026-09-22）。

调研结论：**没有 YGO 对手预测论文**；可迁移的先例：DouZero+（LSTM 历史 → 下家手牌分布，拼进策略输入，Botzone 第一）、Hanabi BAD/LBS（以策略为似然的贝叶斯信念，含非提示动作）、Skat/Scrabble（「他本可以打 X 却没打」= 负证据，用 π(观测动作 | 隐藏状态) 加权世界）、Ataraxos（信念网络做搜索采样，击败顶尖人类）、Hearthstone HDT 牌组预测器（按已现卡过滤 meta 卡表 + 频率先验，Bursztein 2016 > 95% 下张卡准确率）、SkyNet/BEPAL（辅助头即可 +194 Elo）。**没有人做过三通道消融**；DouZero+（作输入）与 SkyNet（作损失）都有增益，所以两者都做。

设计：
- **预测目标（真值全部来自自博弈模拟器）**：(1) 牌组类型：K 个 meta 类型 + 「other」的 softmax；(2) 牌组剩余构成：对「meta 并集 + 泛用卡」中每张卡预测主/额外剩余份数 0–3（多头分类而非 sigmoid，保证份数校准）；(3) 手牌：每张候选卡「≥1 张在手」概率 + 角色位（有手坑 / 灰流丽 / 增 G / 原始生命体 / 延伸）；(4) 每个盖卡区域的类别分布（角色 + top 候选）；(5) 「我下一步检索/特召会被响应」的概率（动作级小头，直接消费不响应证据）。
- **损失**：逐头交叉熵，已公开信息按构造置 1、已现份数从剩余中扣除；后期加大手牌/盖卡头权重；报告 ECE 校准误差（喂过度自信的信念比不喂更糟）。
- **「不响应」证据编码**：每当对手有合法速攻/手坑窗口而放弃，在公共历史中插入显式「响应窗口 + 放弃」token（触发类型：检索 / 从卡组特召 / 堆墓 / 第五次召唤 / 攻击宣言，对手场面，LP，回合）。Transformer 从**当前联赛对手群体**的自博弈数据学到 P(手牌 | 在该触发放弃)，因为对手会策略性藏手坑，所以学到的是与策略相关的后验，而非「没响应 ⇒ 没有」的朴素规则。每次联赛更新后用新数据重训信念头。
- **meta 先验**：牌组构成头以 meta 卡表混合初始化；HDT 式精确过滤（与已现卡一致的 meta 牌组数、频率加权卡分布）同时作为硬基线与输入特征；自博弈牌组按 meta 分布采样使先验与训练数据一致，并混入 off-meta 噪声（随机换卡）以容忍离群。
- **三通道消费**：(a) 信念头输出（detach）拼进策略输入；(b) 同一组头作为共享主干的辅助损失；(c) 历史条件的非对称 critic V(h, 真实隐藏状态)。三者分别消融。后期 PIMC 搜索复用手牌/盖卡头做确定化采样，并按策略似然给采样世界加权（Skat / LBS 做法）。
- **陷阱**：actor 绝不见真值（imitation gap）；critic 只看状态不看历史会有偏；信念头对一个对手群体校准，对人类或新联赛会漂移；有限 meta 列表对 rogue 牌失效（Eger 2020 单回合只有 57.7%）故保留 other 类与离群逻辑；卡级头类别数大，限定到 meta 并集 + 泛用卡，其余走哈希/嵌入；detach 防止策略把信念头当旁路。

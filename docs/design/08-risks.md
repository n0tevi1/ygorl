# 风险与备选

> 属于 [ygorl 设计文档](README.md)。状态：已评审通过（2026-09-22）。


| 风险 | 备选 |
|------|------|
| edo9300 核心在多线程下暴露隐藏全局状态 | 退化为多进程池，接口不变 |
| ygo-combo-solver 与 edo9300 核心不兼容或 arena 移植困难 | 先以其二进制离线产示范（只需 .ydk 输入）；中局开局退回种子重放；快照作为后期项 |
| Lua 引擎吞吐低于预期，M4 训练不收敛 | 缩小牌组池、缩短对局、BC 预热承担更多；必要时上 PufferLib 或多机 |
| 事件流 Transformer 算力 2–4×，单 GPU 吃紧 | 缩短 L、用 LSTM 基线先跑通，Transformer 作升级 |
| 信念头在新对手群体上漂移 | 每次联赛更新后重训信念头；评估时报 ECE，超阈值即触发 |
| MD 禁限表/卡池数据源不稳定 | 数据快照进仓库版本化；解析器与来源解耦 |
| 协同图挖掘漏掉脚本用非常规写法的卡 | 与 Yugipedia 关系、文本嵌入相似度并联；召回检验 < 80% 时补规则 |
| 策略「不会玩」导致 rogue 牌组误判 | 每候选微调预算 + 学习曲线；多快照取最好成绩 |
| 代理模型对新系列泛化差 | 加卡/效果文本嵌入均值；在线更新 |

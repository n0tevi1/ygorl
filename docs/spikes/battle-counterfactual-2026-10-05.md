# 剩余攻击行为的反事实诊断（2026-10-05）

修正后BC对Greedy并无可靠收益；菜单可攻击却选择main2不一定错误。
固定诊断范围为前一完整面板中new64×1/new128×2对Greedy的全部160局，
只检查策略选择main2且host提供可直接攻击选项的状态，不按输赢筛选或挑种子。
原始完整动作/响应/结果必须再次一致；Greedy对手从原agent seed开始按每个原决策推进，
逐项断言与原记录一致，确保分叉前的随机数和记忆状态准确。

每个候选状态保存snapshot，对每个host明确允许直接攻击的攻击者分叉；
强制这个攻击，然后用固定Greedy规则完成本战斗阶段，原Greedy对手状态深复制后正常回应。
每枝最多128个后续host动作，退出战斗/回合即止。检查全程健康。
若在这个战斗阶段赢局，保存完整起点、prefix+分叉动作、响应，并独立冷重放确认。
只把这种完整见证叫“该状态存在可赢的替代战斗线”；若原游戏输了，可确认策略错过一次
对固定Greedy的获胜机会。它不证明对最优对手必胜，也不等价于统计显著的总胜率提升。
未找到/触及guard只报告无见证或unknown，不推断原选择正确。
这项诊断不修改训练/验证/评估面板、不从测试状态补当前训练，也不作为checkpoint选择依据。

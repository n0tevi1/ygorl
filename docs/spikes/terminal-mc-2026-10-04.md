# 完整终局 critic 监督：matched RL pilot

目标：#61 尚未完成的真实终局监督对照；终极指标是完整对局强度。旧 `critic_lam=1`
仍有 Expected-SARSA 控制变量与段末 bootstrap，不能作为这个问题的负证据。
本轮在 main `2fad27a` 之后、隔离 worktree `codex-terminal-mc` 实施；默认训练配方不变。

## 在正式结果之前固定的协议

- 环境 `md-2026-09` 的 20 套合法 meta 牌组；均匀 cross 配对，不按 meta share 加权。
- BBL05-u400 actor 热启动，网络 64×1、事件 64；**两个臂均为同种子新 critic 和新 optimizer**，
  不是恢复旧训练的全部状态。起点 SHA256 `1ff78493781873a974cdaf11fccf56935199c2268780c4bd967ff442c296cd9f`。
- 两训练种子 2026100410 / 2026100411；每种子 lambda / terminal 两臂。
  每臂固定 64 次更新，每次 32 个槽各一完整局，即 2,048 游戏预算，共 8,192 游戏。
  全槽同步收集、按槽排序事件，行为策略局内固定；同种子验证初始模型及第一批数据哈希相同。
- 两臂都采用完整游戏采样，游戏拼接成单列；在每个终局截断回溯。
  截断/错误整局不参与训练，仍计入游戏和决策预算；不补采、全批无有效行则失败。
  长局贡献更多行，报告实际行数与墙钟；这不是严格等行数或等 GPU 时间的对照。
- 唯一配方差异：Q/V 回归目标为 Expected-SARSA(λ=.5) 或真实终局 z。
  策略优势均为 VRPO(λ=.5)，gamma=1、turn_discount=1；其余 PPO、PFSP、快照参数沿用默认。
  无 critic warmup、无 overlap、无 bf16。max_decisions=4000，max_turns=200。
- 先用 seed=2026100409、8 槽 × 2 更新检查内存/运行；冒烟不参与选臂或最终评分。
- 不依 Greedy 或中途结果挑 checkpoint，固定用 update 64。保留起点作为第五个候选。
  外部对手固定 seed1 / league / long，独立评测 seed=2026100412，128 个四重配对，
  5 候选 × 3 对手 × 512 局 = 7,680 完整对局；所有候选共同剔除错误配对。
- 主比较为两个训练种子等权平均 terminal−lambda；另看平均 terminal−冻结起点。
  以配对为 cluster 跨对手/种子一起 bootstrap；每种子的差单独报告。
  两个平均比较都需点差 ≥2pp 且 95% CI 下界 >0，才进入更长预算复核；不挑最好种子。
  这是联合通过门槛，不能从多个比较中任选一个显著即扩训。区间不覆盖训练种子总体不确定性。
- 更新前的新完整游戏记录 Q/V 对终局 z 的 EV 和 MSE，两臂使用同一指标。
  不把对各自 bootstrap 目标的训练 EV 相比来宣称校准变好；终局 EV 也不能替代动作排序/对局强度。
- 如果有非有限损失、全批截断或 OOM，停止并记录；高截断率需先处理采样有效性。
  本轮未通过则不直接延长相同配方；短预算负结果不外推为终局监督或大规模 RL 的普遍上限。

## 原始论文与实现核查

核对 [Fan & Farina, arXiv:2605.19235v1](https://arxiv.org/html/2605.19235v1) §3.2 / §4.2：
当前 Expected-SARSA 回溯对应其公式 (3.2)/(3.3)，λ=1 仍不是 MC 标签。
论文的 on-policy score-function 无偏结论要求 λ=1；方差改善还依赖 Q 足够准确，
不能直接保证本项目 λ=.5、近似 critic 的优势方向正确。

论文训练过程会用当前 actor 概率重算 policy expectations，并把 actor 与 critic 的优化分开；
本项目 `PPOLearner.update` 则在整批更新前固定优势，同一步优化共享主干与 Q/V。
因此这是采用 Q-boosting 估计器的 PPO 变体，并非论文完整训练算法的逐项复现。
这项差异本身不证明代码错误；本轮两臂都保持现有更新方式，不把它混入终局目标对照。

论文斗地主运行约 26.5 亿 timestep；本轮只是一项小预算机制 pilot，
不能将短训练的负结果解释成“继续扩大训练无效”。上述论文细节只作为设计参考，
实际算法选择仍由本项目的独立对局证据决定。

## 根据结果选择的下一步：独立确认完整游戏 RL 配方

一个正向线索是 **lambda 两种子平均较起点 +6.27pp [ +3.69,+8.89 ]**；
两个种子均为正，三个外部对手上的平均差也为正。它是这次 MC 对照的辅助发现，
还不能把改善唯一归因于完整游戏采样：MD meta 训练分布、额外训练预算等一起改变了。
也不选择点分最高的种子当作“已证明最佳”。

现在固定独立确认：保留完全相同的 lambda 配方，第三个训练种子 **2026100413**，
64 更新 × 32 游戏 = **2,048 局**；相同冻结 actor 起点、fresh critic/optimizer。
只评固定 update 64，对同三外部对手，用全新 seed **2026100414**、128 四重配对，
候选与冻结起点共 **3,072 局**。主比较为这一个新种子减起点，门槛仍为 ≥2pp 且 CI95 下界 >0；
不复用前一面板挑种子、checkpoint、更新数或超参数。共同剔除引擎错误配对，报告并共同排除
限时局做敏感性分析；截断敏感性不能救活失败的主检验。
训练遇非有限值、OOM、全批无有效行，或至少 128 局后截断比例 >2% 即停止。
通过后才把此配方作为后续更长预算/标准固定段采样对照的起点，仍不声称达到人类顶尖强度。

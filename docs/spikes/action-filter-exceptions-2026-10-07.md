# 动作过滤范围与合理自否定反例（2026-10-07，#218）

冻结的 history masker **未通过合理例外检查**：在两个原生引擎确认的濒死局面中，
它把能避免立即败北的自灰概率压低约 98%。只惩罚 Ash、不惩罚 pass 的版本同样失败。
候选保持实验状态，不进入 PPO 或默认 agent；此前普通检索标签的零误标不能解释为战术安全。

后续[前序决策检查](action-sequence-diagnosis-2026-10-07.md)确认可以先清场再检索，或在对方回合不发动。
本页反例属于前序错误后的补救测试，不能作为主动发动致死检索的示范。

## 引擎反例：检索导致致死伤害

对方场上有 Trickstar Lycoris（35199656），己方 Radiant Typhoon Chant（67115133）已发动。
该检索会使 Lycoris 对己方造成 200 伤害；己方仅剩 200 LP 时，Ash（14558127）否定自己的检索能避免立即败北。
Chant 在原审查检索卡集合内，目标窗口恰有 Ash/pass 两个合法动作，因此会进入旧推理支持范围。
这一结论针对已到达的响应窗口，不表示此前发动 Chant 是好决策。

使用两个合规 40 卡自定义卡组、固定顺序、不洗牌、seed 2026100780。
己方回合组从双方 400 / 8000 LP 开始，己方通常抽卡先受 200 伤害，目标窗口为 200 / 7800 LP；
对方回合组从双方 200 / 8000 LP 开始，己方先盖 Chant，在对方通常召唤 Lycoris 后发动。
**初始 LP 覆盖应用于双方**。这不是标准初始 LP 的随机自然对局，也不是只改变己方 LP 的因果实验。

| 响应时机 / 己方目标 LP | pass 后果 | Ash 后果 | 原 Ash 概率 | 双候选 / 仅 Ash 过滤后 |
|---|---|---|---:|---:|
| 己方回合 / 200 | 立即败北 | 保留 200 LP | 4.0634% | 0.0783% / 0.0783% |
| 己方回合 / 7800 | 降至 7600 LP | 保留 7800 LP | 4.7985% | 0.0931% / 0.0931% |
| 对方回合 / 200 | 立即败北 | 保留 200 LP | 2.8533% | 0.0552% / 0.0552% |
| 对方回合 / 8000 | 降至 7800 LP | 保留 8000 LP | 3.4664% | 0.0673% / 0.0673% |

己方回合低 LP 的 Ash 分支随后按脚本使用 Raigeki、通常召唤 Gene-Warped Warwolf、攻击，取得原生胜利终局。
这证明存在这条脚本胜线，不是原 actor 自行发现胜线，也不是对最优对手的胜率保证。
对方回合组和高 LP 组在该连锁结束后的首个决策停止；仅报告已观测后果，不把存活称为整局获胜，
也不为高 LP 对照宣称全局最优动作。

两个低 LP 窗口的 Ash 风险分分别 .998705 / .996665，高 LP 为 .998781 / .997033。
这些是未校准分数。它们随致死条件的改变几乎不变，却强烈抑制救命响应，违反预注册例外 gate。
只有两个相关合成反例，不能估算自然发生频率或总体误拒绝率。

## 根因审计及边界

1. **不是 LP 输入消失。** 同一时机的高低 LP 配对只改变 `globals[5:7]` 和有效事件行的 LP 列 18/19，
   其他输入一致。冻结 history 最大绝对差分别 .30856 / .29163，action 表示也改变，信息已进入表示。
   这不证明表示充分编码了伤害后果，但排除了输入完全相同的解释。
2. **本例没有证明旧摘要漏算伤害。** 复用旧 `effect_summary` 审计完整 pass 事件，四组都得到 hand_gain=1、
   lp_cost=200。低 LP 分支还缺少正常 ChainEnd。按旧接受条件，这些窗口应被拒绝标注，不能宣称教师已把它们误标为 pass 好。
   Lua 回调名称不足以推断协议事件顺序，应以原生事件为准。旧分支采集还未完整保留无后续决策的终局事件；新工具显式补齐。
3. **已证实的是标签覆盖与推理范围不一致。** 训练只含通过局部资源检查的偏好，推理却仅凭卡片集合和两候选等条件给更宽的状态打分。
   未知窗口没有监督约束；三头一致也没有阻止错误外推。与“学到归属/资源捷径”相符，但尚未通过消融证明内部唯一机制。
4. **单边过滤修复不了错误判断。** 不惩罚 pass 可避免主动鼓励某些对方窗口发动 Ash，却仍然会压低有用的自灰。
   该结果不能证明原 actor 所有自灰的单一根因，也不否定普通情况下局部纠错的效用。

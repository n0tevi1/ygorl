# 灰流丽局部纠错：数据、目标与遗忘对照（2026-10-07）

状态：方案与现有样本审计完成；未训练纠错模型、未修改PPO默认目标或合法动作。
跟踪 [#218](https://github.com/n0tevi1/ygorl/issues/218)，关联 #61 / #83 / #92。

## 问题边界与已核验接口

用户指出亏血攻击有时用于让己方怪兽离场、腾场满足发动条件。这一例外必须纳入标签审核。
此前case3的两次攻击都没有让己方或目标怪兽离场，故该例并未实现腾场；但不能由此构建全局“ATK不足禁止攻击”。
战斗标签还需审查效果、送墓/破坏收益与后续线路，不能把LP变化当最终效用。

优先处理case1/d6：灰流丽否定自己的Radiant Typhoon Vision检索；只有Ash/pass两个合法选项。
单点改成pass已验证检索正常结算且保留Ash，完整续局仍输，不能用两条都输的终局回报提供清楚的局部好坏标签。
这说明局部监督值得试验，不代表已经证明它提高胜率。

实读seed0/warm128检查点：128宽、2层board Transformer、2层history Transformer，事件历史启用；
card_text/effect_text/card_facts均关闭。己方连锁归属存在于原生events张量，EventEmbedding将player作为类别输入，
经历史摘要进入board/context及动作头。不是历史模块关闭；内部为何没形成合理偏好仍未解决。
当前网络不直接接收自然语言规则，需用局面张量和动作监督表达教学。

仓库已有BCData、按合法动作交叉熵拟合、策略加载与保存、PPO参考策略KL、原生历史输入。
PPO目前没有独立纠错样本损失；不能宣称现有BC prior KL已经实现纠错样本复习。
旧BC课程以先攻展开和Greedy自身战斗回合为主，不能视为已覆盖可靠的双方连锁响应教学。
也不能把Greedy的“尽量连锁”行为直接当这一任务的教师。

## 优先方法：小规模监督纠错，持续混入RL

1. 在新对局中采集学生的真实Ash响应窗口；保存原生观测、合法选项、当前连锁及发动归属、checkpoint/环境身份、
   重放前缀。按对局/发牌组隔离数据，同一局的不同checkpoint或两个座位不得跨训练与测试。
2. 对高置信度局面做人工/确定性规则初筛，再用引擎分支核验实际被无效的连锁与成本。需要知道的隐藏信息不在
   actor输入中时，不依据真实对手手牌决定标签。争议或存在特殊收益的局面保留为未标注，不强行贴pass。
3. 二选一且替代明确时，最小目标为`-log π(pass | s)`；多个合理动作时，只约束已确认的好/坏动作偏好，
   例如`softplus(-(logit_good - logit_bad))`，不能把某个好动作提升为唯一专家答案。
4. 加入经过审查的“应该灰对手”的正例、应该保留Ash的反例，并保留普通展开/战斗数据复习。
   “对手发动可灰效果”本身不足以自动推出必须灰，必须考虑时点、收益与手坑资源。
5. 候选总目标为`L_PPO + λ L_correction + β KL(π_before || π_current)`；这里额外KL取普通保留局面，
   不替代现有PPO的EMA参考KL。其作用是约束无关能力漂移，不能单独保证不遗忘。
   λ/β在开发验证上选择、最终测试前冻结，并记录纠错采样比例和实际额外计算。

该设计借鉴示范辅助RL及在学生状态分布上收集标签的思路，而不是声称直接实现论文算法：
[DAPG](https://arxiv.org/abs/1709.10087)、[DAgger](https://arxiv.org/abs/1011.0686)。
后续更复杂局面可以比较轨迹片段偏好学习，但当前明确二选一不必先增加奖励模型；
参见[轨迹偏好学习](https://arxiv.org/abs/1706.03741)。

## 最小实验与通过条件

先冻结独立新数据、标签理由与训练/验证/测试分组，再登记运行预算。当前53窗口不满足泛化证据要求。
首轮建议同一warm128起点的三臂：纯PPO、一次纠错预热后PPO、PPO持续混入纠错；三种随机种子。
在0/8/32更新检查保持情况，报告相同RL采样预算下的结果和额外教师梯度/用时，不把额外计算隐去。
若要声称收益不只是增加优化步，还需普通复习的匹配额外计算对照。

验收同时看：

- 未见过的已确认坏局面上，self-Ash的平均概率及实际采样错误率，而非只看argmax。
- 已确认应响应对手的局面上，正确响应概率/漏打断率；防止退化成永远pass。
- 按牌组、效果类别、先后手、连锁长度分组，重复窗口按来源对局聚类；另留未见检索卡的泛化测试。
- 新配对完整对局胜率与区间、引擎健康、普通展开和战斗保持；局部准确率提高不自动通过强度验收。
- 接续PPO后0/8/32节点的纠错保持与强度变化，以区分“一次教会又忘掉”和持续教学收益。

若监督在训练局面都学不会，先查标签/梯度/表示；若训练会、留出不会，优先查覆盖与记忆卡名捷径；
若纠错后接续PPO遗忘，比较持续复习；若self-Ash减少但对手响应也下降，视为失败。
全局硬mask与固定“self-Ash扣分”不作为首选：前者限制策略空间，后者把启发式变为终局之外的优化目标。
辅助预测“这次会无效哪条连锁、归谁”可作为后续表示诊断，但预测准确不等于会正确决策。

# 调卡组：给定一套牌的局部搜索（目标 1、T6.2）

> 设计依据：[design/05-deck-building.md](design/05-deck-building.md)、[design/02-challenges.md](design/02-challenges.md) C8（内层策略作评估器、外层搜索）。
> 代码：`ygorl.build.tuner`，命令行 `tools/tune_deck.py`；对局走批量评估（[evaluation.md](evaluation.md)「批量评估」）。

给一套基础卡组，在它附近找「换一张卡」后在当前环境里打得更好的版本。「更好」= 由同一个策略驾驶时，对环境 meta 牌组（按占比抽，由同一或另一策略驾驶）的胜率更高。

## 流程

1. **基础卡组的类型**：牌组语料（[data.md](data.md)「牌组语料」）里与它逐卡张数 L1 距离最近的卡表的类型。
2. **候选卡**（`tech_pool`）：同类型其它卡表里出现过的卡（引擎变体），加上环境 meta 卡表里出现最多的 `--meta-top`（默认 60）张（手坑、解场卡等泛用卡）。
3. **改动**（`neighbors`）：同一区域（主卡组 / 额外卡组）里「换下一张、换上一张」，张数不变；每个改后卡组都要在环境下合法。随机取 `--candidates`（默认 64）个。
4. **公共随机数**（`PairedEvaluator`）：第 `k` 对对局对所有候选和基础卡组都相同——同一种子、同一对手（按 meta 份额抽）、先后攻各一局；
   比较用逐对的配对差，而不是两个各自有噪声的胜率。
5. **逐轮淘汰**（`successive_halving`）：所有候选先打 `--first-pairs`（默认 25）对，保留配对差靠前的一半，累计对数翻倍，直到剩 `--finalists`（默认 3）个；
   基础卡组每轮与存活候选打同样的对局。
6. **复核**（`validate`）：决赛候选与基础卡组在 `--validation-pairs`（默认 200）对**新的**对局（从未用于搜索的种子）上重打；
   搜索用过的对局有选择偏差（64 个中性候选里最好的那个也常常「显著」），所以只用复核的配对差与 95% 区间判断，最优候选的区间下限 > 0 时写出 `tuned.ydk`。

替换是**原位**的：换上的卡放在换下那张卡的位置。洗牌按种子与张数排列位置，所以同一种子下基础卡组与候选的起手、抽牌只差这一张卡——这才是公共随机数。
引擎里出错的对局记为缺失（不是平局），配对差跳过缺失的对；报告里有错误局数。

## 前提与限制

- **评估器要会打这套牌**：只在 10 套测试牌组上训练的策略（PF）在没见过的牌组上对 Greedy 只有约 0.53（[benchmarks.md](benchmarks.md)），
  用它调没见过的牌没有意义——新换上的卡它多半不会用，搜索会偏向「不改」。先用牌组语料训练（T4d.1），再调。
- 一张卡的改动通常只带来 1–3% 的胜率差，要上千局才分得清；逐轮淘汰把大部分局数留给有希望的候选。
- 只做单卡替换；多卡改动、份数增减（主卡组 40–60 张之间）与额外卡组整体重构留待后续（可反复调用或做爬山）。
- meta 对手由策略驾驶，结论只对「这个策略水平下的环境」成立；换更强的策略要重跑。

## 有依据的子代：信号库（#109，`ygorl.build.signals`）

组牌进化（spec #105，[spikes/deck-evolution.md](spikes/deck-evolution.md)）的子代生成。M3 的结论是：起手效应、critic 起手值、死卡 / 闲置 / 使用率、使用后优势
**都预测不了逐卡的留一真值**（Spearman ≤ 0.28，门槛 0.5，[benchmarks.md](benchmarks.md)「牌组迭代的先行测量」），所以逐卡价值只从评估里来：

- **`CardValueModel`**：每次亲本对子代的配对评估（差 = 子代 − 亲本，带标准误）是一条线性观测：换上的卡的价值之和 − 换下的卡的价值之和。
  卡在某类型牌组里的价值 = 卡效应 + 卡 × 类型效应，先验分别为 N(先验均值, 0.03²)、N(0, 0.02²)，按 1 / 标准误² 加权，解一次带先验的加权岭回归（高斯后验）。
  没有数据时回到先验；数据多时趋近评估结果；同一张卡在别的类型里测过，会经卡效应部分传过来。
  观测按行堆成矩阵一次求精度矩阵，Cholesky 分解缓存到下一次 `add`（3,000 条观测、约 3,000 个未知数约 8 秒）。评估只观测**差**，所以单卡的绝对价值始终只和先验一样确定；排序与预测用 `gain(into, out, type)`（按联合后验算，差的不确定度小得多），
  Thompson 抽样也按联合后验抽（`sample`）。
- **`Calibration`**：每个廉价信号的（预测，实测）对。攒够 `min_pairs`（默认 20）对后，权重 = 与实测的 Spearman，95% 区间（Fisher z）不含 0 才启用，否则为 0（停用）；
  之前用默认权重，M3 没过门槛的信号默认权重都是 0（Spearman 的 Fisher z 标准误取 √(1.06 / (n − 3))，Fieller 1957）。`combine_prior` 把启用的信号（逐卡 z 分数 × 权重 × 0.01）合成模型的先验均值。
- **`protected_cards`**：信号会误判的卡，进化不按信号把它们换下：胜利条件（脚本调用 `Duel.Win` 的卡，以及该脚本点名的本卡组的卡，含 `CARDS_*` 常量点名的，如 Exodia 与其四肢、命运看板与幽灵信息）、
  检索目标（本卡组另一张卡能从卡组检索 / 特殊召唤它，协同图 `search` / `special_summon` 边、扇出 ≤ 30）。
- **`informed_children`**：每个亲本默认 6 个有依据的子代 + 2 个探索子代，全部合法、互不相同。有依据的子代先对卡组与候选卡的价值做一次 Thompson 抽样，
  再抽包大小（1–3），把抽到价值最低的卡（受保护的除外）依次配上同一区域里抽到价值更高的候选卡，只保留「抽样增益为正且改后合法」的改动（不换下本包刚换上的卡，也不换回本包换下的卡），直到包满——
  一个子代里的改动方向一致（都是换下低、换上高），真实 Δ 更大，才评估得出来（M1：确认 2 pp 要约 885 对）。
  探索子代是随机的合法单卡替换（`neighbors`），保留发现「模型还没见过的好卡」的机会。

## 进化评估器：前二 Thompson 采样、critic 控制变量与序贯复核（#110）

组牌进化（[spikes/deck-evolution.md](spikes/deck-evolution.md) §4）在上面的配对评估上换掉「逐轮淘汰 + 固定 200 对复核」；逐轮淘汰保留为对照。
`PairedEvaluator.play([(卡组, 对局序号范围), ...])` 让每个卡组打各自的对局序号，所有卡组仍在一批里打（GPU 吃满）；`scores` 是它的特例。

- **前二 Thompson 采样**（`ygorl.build.selection.top_two_thompson`，Russo 2016）：
  - 每个子代先打一批（`batch`，默认 25 对）；之后每轮做 `batches_per_round`（默认 4）次前二抽样，每次给一个子代加一批，一轮的对局一次打完；
    亲本只补子代用到的对局序号（可传入诊断已打的亲本对局 `base_scores`）。
  - 后验：每个子代的配对差 Δ 为高斯，先验 N(预测增益, sd²)（`CardValueModel.gain` 的均值与标准差；默认 N(0, 0.05²)），
    似然用观测到的逐对差，逐对方差为全部子代的合并经验方差，外加 10 对 σ = 0.212（M1）的伪观测，防止开头几批方差估计失真。
  - 停止：后验均值最高的子代 P(Δ > 0) > 0.95，或子代对局满 600 对（`max_pairs` 只算子代对局，不算亲本）。
    返回每个子代的对局数、原始配对差、后验均值与标准差、P(Δ > 0)、P(最好)。
  - 合成测试（8 个子代，一个 +8 pp，其余 −4 到 +1 pp，逐对差 σ ≈ 0.21，其中亲本自己的噪声 0.1 进入每个子代的配对差，使子代之间相关）：
    100 个种子里选中真值最好的 92 次，平均约 280 对（没有亲本噪声时 87 次、271 对）。
  - 后验按「子代之间独立」算，没有建模共用的亲本噪声，P(最好) **偏保守**：400 个种子里 P(最好) 在 0.5–0.8 的子代有 96% 真是最好，
    0.05–0.2 的只有 2%。P(Δ > 0) 大体校准（选中子代平均 0.98，真为正的比例 0.98）。P(最好) 只作报告，不用于判定。
    失手几乎都是第一轮（每个子代 25 对）就把一个中性子代判为 P(Δ > 0) > 0.95：8 个子代的最大噪声在第一轮就可能越线（约 10%）。
    这类误停由复核在新种子上拦下，代价是一次复核的对局。
- **序贯复核**（`sequential_validate`）：选中的子代与亲本在从未用于搜索的新种子上（序号从 1,000,000 起），每 `look`（默认 100）对看一次，上限 `cap`（默认 1,000）对。
  第 k 次看的重复置信界 = 均值 ± z_k·s/√n（s² 与 Thompson 一样计入 10 对 σ = 0.212 的伪观测，短序列里全是平局的配对差不会给出零宽区间），z_k 由 Lan–DeMets 的 O'Brien–Fleming 型 α 支出函数算出（单侧 α = 0.025，与原来 95% 双侧区间的下限一致；
  按布朗运动在未停区域上的密度递推精确求界，5 次等距看的界 4.88 / 3.36 / 2.68 / 2.29 / 2.03 与教科书一致）。
  下界 > 0 接受；到上限仍未接受则拒绝。
  无望（futility）界单独用固定的 z = 1.645（`futility_z`）：均值 + 1.645·s/√n < `min_effect`（默认 2 pp）就判为无望、提前停。
  它是非约束的（只会少接受），所以不影响 α；若沿用 O'Brien–Fleming 的 z（10 次看的第一次是 7.0），无效应时平均要打 979 对才停，几乎等于上限。
  合成模拟（逐对 0 / 0.5 / 1 分、亲本与子代逐局 80% 相同，模仿公共随机数；α = 0.025）：无效应时 4,000 次中误接受 2.5%，平均 393 对就停；
  真实差 +2 / +3 / +5 pp 时接受率约 0.76 / 0.97 / 1.0。`min_effect` = 1 pp 时无效应平均要 666 对，+2 pp 的接受率只高到 0.80，所以默认取 2 pp。
- **critic 控制变量**（`ygorl.build.control.CriticControlVariate`，评估器的可插拔 `control`，**默认关闭**）：
  - 每局得分减去 β·[V(实际起手) − 同一卡组 K 个替代洗牌的平均 V]，V 是特权 critic 在第一个决策点、从本卡组一方看的值（首个决策是对手的就取负）。
    替代洗牌只重排本卡组，对手顺序、先后攻、引擎种子不变；每个替代洗牌与实际洗牌一样是均匀洗牌，所以扣除项的期望为 0，无论 critic 好坏都**无偏**。
  - 亲本与子代各按自己的卡组算；替代洗牌的排列只由种子决定，原位替换的子代与亲本得到「只差被换的卡」的替代起手，扣除项与对局一样逐对相关。
  - β 是参数（默认 0.5：把 critic 的 ±1 尺度换成得分的 1 / 0，只对校准好的 critic 是最优系数；方差最小的系数是 cov(得分, 手气) / var(手气)）。
    **β 只要不依赖被调整的这批局，估计就无偏**：E[β·手气] = β·E[手气] = 0。所以 β 可以在不相交的局上拟合（M5 在留出的牌组上拟合），
    但不能在同一批局上拟合（那样 β 与手气相关，带来小偏差）。每局代价是 1 + K 次只到第一个决策点的前向，不打完。
  - critic 读出的「手气」越准，降得越多；但 critic 自身的噪声也会进来：合成测试里噪声大于起手所能解释的部分时，方差反而**变大**。
    critic 在第一回合的解释方差只有约 0.1–0.15，所以预期降幅不大。按 spike 的门槛，M5 测得方差降低 ≥ 30% 才默认启用。
  - 还要注意：公共随机数下亲本与子代的起手只差被换的卡，两边的「手气」在配对差里本来就大多抵消；控制变量只能再扣掉被换的卡在起手时带来的那部分手气差，
    对单卡改动的配对差帮助有限（CPU 冒烟：1 套牌、1 个留一子代、16 对、K = 4，单局的手气解释方差 0.12，配对差方差几乎不变），打包多卡的子代可能多一些。
- **测量脚本**：`tools/deckevo_m5_cv.py`（M5：M2 式的亲本 / 留一子代，同一批局上比较扣除前后配对差的方差：β = `--beta`，以及每套牌组用其它牌组拟合的 β（留一套牌组）；
  **留出的降幅**决定 M5 是否通过。另报样本内最优 β 与单局的解释方差，只作诊断）；
  `tools/deckevo_eval_compare.py`（同一批亲本上，调卡组 MVP 与「有依据的子代 + 前二 Thompson 采样 + 序贯复核」的每接受一次改动的对局数）。结果写入 [benchmarks.md](benchmarks.md)。
